    API key Twelve Data

    Kripto langsung jalan tanpa key. Untuk XAU/USD asli, forex, dan saham, aplikasi butuh API key gratis dari Twelve Data.

    1. Buka twelvedata.com dan daftar paket Basic (gratis).
    2. Salin API key dari dasbor Anda.
    3. Tempel di bawah lalu simpan.
